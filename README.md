# CampusEdge – Premium College Management UI

CampusEdge is a UI-only academic & exam administration experience tailored for hackathons. It delivers elegant beige/cream visuals, role-based dashboards, and conceptual AI support while staying entirely on HTML + internal CSS (no external dependencies).

## Palette & Design Language
- Primary: `#8B6F4E`
- Secondary: `#CBB89D`
- Accent: `#E6D8C3`
- Background: `#FAF7F2`
- Text: `#2E2A24`
- Typography blends Libre Baskerville (headings) with Source Sans Pro (UI copy).
- Soft shadows, rounded cards, responsive grids, and consistent hover effects reinforce a premium university feel.

## Pages & Highlights
| Page | Focus |
| --- | --- |
| `index.html` | Landing page with hero CTA, flagship feature grid, role cards, campus value section, workflow steps, operational insights, and testimonials. |
| `login.html` | Role-based login UI featuring a refined form, remember-me toggle, and a security/information panel. |
| `student-dashboard.html` | Attendance stats, hall ticket with QR placeholder, theatre seating, AI assistant chat, academic timeline, resource hub, and announcements. |
| `faculty-dashboard.html` | Digital attendance table, announcement list, AI helper, cohort summaries, and quick resource shortcuts. |
| `admin-dashboard.html` | Student/faculty oversight cards, seating arrangement builder, hall-ticket generator, communications list, and KPI widgets. |
| `management-dashboard.html` | Executive overview metrics, analytic cards, and decision-support focus areas for leadership. |

All pages share the same palette, typography, and navigation so judges can move between personas instantly.

## Usage
Open `index.html` in any modern browser to explore the landing page. Use the navigation links or `login.html` to move across the student, faculty, admin, and management experiences. The project is UI/UX only—no backend wiring is required.
